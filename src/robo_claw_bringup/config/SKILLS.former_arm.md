# 포머 팔 장착 로봇 전용 스킬 가이드 (SKILLS.md)

이 가이드는 **Former0045 + AgileX Nero(7-DOF) 팔** 조합에만 해당하는 규칙입니다.
포머 본체의 주행·관측 규칙은 그대로 따르며, 팔이 추가된 만큼 조작 스킬의 사용 조건이 달라집니다.
일반적인 스킬 선택은 시스템 프롬프트의 `[도구 선택 전략]`과 `[파라미터 규칙]`을 따르되,
아래 차이점을 반드시 준수합니다.

---

## 로봇 특성 & 제약

- **팔 보유**: 7-DOF 팔(`joint1`..`joint7`, MoveIt group `arm`)이 장착되어 있습니다.
  조작 계열 스킬(`arm_pose`, `move_joints`, `move_pose`)이 카탈로그에 등록됩니다.
- **그리퍼 장착**: AgileX 그리퍼(`agx_gripper`, group `gripper`)가 장착되어 있습니다.
  `open_gripper` (50mm 개방), `close_gripper` (0mm 폐쇄), `move_joints` (`gripper` 0.0~0.1m) 사용이 가능합니다.
- **Stretch3 전용 서비스 없음**: `/stow_the_robot`, `/switch_to_navigation_mode` 가 없어
  `stow_for_navigation`, `switch_stretch_mode`, `stretch_*_mode` 는 사용할 수 없습니다.

---

## 팔 조작 규칙

- **`home` 은 "접은 자세"가 아닙니다**: AGX/Nero 드라이버의 `/move_home` 은 모든 조인트를
  0 rad 로 보내는 **수직으로 뻗은 자세**입니다. "팔 접어", "home 자세로" 요청에 `arm_pose`
  `pose_name='home'` 을 쓰면 팔이 이미 그 자세이므로 **움직이지 않고 종료**될 수 있습니다.
  이때는 "이미 home 자세입니다" 라고 사실대로 보고하고, 접은 자세가 필요하다면 `stow`
  같은 접힘 자세가 설정되어 있는지 확인하세요. 설정이 없으면 완료했다고 말하지 말고
  사용자에게 알립니다.
- **자세 이름은 설정에 정의된 것만**: `pose_name` 은 아래 이름만 사용합니다. 정의되지 않은 이름을 상상해서 호출하지 않습니다.
  - `home`: 수직 zero (드라이버 `/move_home`, **접은 자세 아님**)
  - `ready` / `carry`: 작업 대기(가슴 앞, TCP 앞 0.30 m / 높이 0.50 m)
  - `stow` / `fold`: 몸쪽 접기(배송·주행 전 안전 자세)
  - `table`: 테이블 앞 낮은 위치 / `reach`: 앞으로 뻗기
  - `side_left` / `side_right`, `wrist_down` / `wrist_up`, `roll_ccw` / `roll_cw`: 동작 범위 시험용
- **팔은 수직 아래로 내릴 수 없습니다**: `joint2` 하한이 -100도라 완전히 늘어뜨릴 수 없고,
  "팔 내려"는 `stow`(몸쪽 접기)로 수행합니다.
- **관절 직접 지정은 `move_joints`**: 조인트 이름은 `joint1`..`joint7` 형식이며,
  팔 URDF 한계를 벗어나는 값을 넣지 않습니다.
- **위치 지정은 `move_pose`**: 기준 좌표계는 로봇 `base_link` 입니다. "조금 올려" 처럼
  방향만 말한 요청에는 `x`/`y`/`z` 를 크게 잡지 말고, 현재 자세에서 작은 변화만 주세요.
  자세(orientation)를 지정하지 않으면 현재 end-effector 자세가 유지됩니다. 로봇 앞쪽
  작업 공간만 사용하고, 로봇 자신의 몸체·카메라·사람이 있는 방향은 목표로 삼지 않습니다.
- **물체 집기/놓기는 직접 시도하지 않습니다**: `grasp`/`place` 시퀀스는 실기 검증 전이므로,
  집기 요청은 팔 이동으로 대신 수행한 것처럼 보고하지 말고 검증되지 않았음을 알립니다.
- **결과 메시지를 그대로 따릅니다**: 스킬 결과가 `already_at_target=true` 또는
  "이미 그 자세" 라면 팔이 움직였다고 말하지 않습니다. 스킬이 실패하면(`success=false`)
  실패 이유를 그대로 전달하고 같은 명령을 연속으로 반복하지 않습니다.
- 팔 스킬이 실패하면 팔 상태(연동·전원·자세)를 확인해야 한다고 보고합니다. 특히
  `arm_status=NO_SOLUTION` 같은 드라이버 오류는 사용자가 팔 제어 PC 의 드라이버 로그와
  전원·비상정지 상태를 확인해야 해소됩니다.

## 이동 전 팔 자세

- 주행 스킬(`navigate_to`, `move_relative`, `tidy_home`, `autonomous_act`) 실행 전에는
  `stow`(몸쪽 접기) 로 팔을 정리한 뒤 이동합니다. `home` 은 수직으로 뻗은 자세이므로
  주행 전 안전 자세로 쓰지 않습니다.
- 이동 중 팔을 앞으로 뻗은 상태로 두지 않습니다.

## 안전

- 팔 이동은 저속(속도 스케일 0.1)으로만 요청합니다. 속도·가속을 높이라는 요청은 거부하고
  설정 변경이 필요하다고 안내합니다.
- 로봇 근처에 사람이 있거나, 팔이 물체·구조물에 닿은 상태로 보이면 조작을 중단하고
  사용자에게 보고합니다. 비상 정지는 팔 제어 PC 의 `emergency_stop` 서비스로 수행되며
  에이전트 스킬로는 노출되어 있지 않습니다.

## 포머 본체 규칙 (유지)

- "집어줘", "가져다줘" 같은 물리적 조작 요청은 팔로 직접 수행할 수 있는 범위만 처리하고,
  물체 파지가 필요하면 동료 로봇 위임 또는 사용자 확인을 거칩니다.
- 정리 요청은 `tidy_home`, 순찰은 `autonomous_act` 를 사용합니다.
- 위치가 불확실하면 사용자의 명시적 지시에 따라 `self_localize` 를 수행합니다.
- 목표 지점에 동료 로봇이 있을 가능성이 있으면 `request_yield_slot` 으로 자리를 요청합니다.

---

### 요약
- Former0045 는 **주행·관측 + 7-DOF 팔** 로봇입니다.
- 기억할 점: **`home` = 수직 zero(접은 자세 아님)**, **접기는 `stow` 설정 시에만**,
  **`already_at_target` 이면 움직였다고 말하지 않음**, **파지 계열은 미검증**,
  **팔 오류 시 반복 대신 보고**.
