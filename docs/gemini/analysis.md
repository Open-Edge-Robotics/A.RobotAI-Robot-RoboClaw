# 로봇 에이전트 구조 안내

이 문서는 RoboClaw의 채널·에이전트·제어 경계를 설명합니다. 상세한 현재 구조는
[런타임 구조](../opencode/README.md)에서 관리합니다.

- 채널은 HTTP·gRPC·메신저 요청을 ROS action/service로 연결합니다.
- 에이전트는 문맥과 라우팅, 네이티브 도구 호출 또는 JSON 계획, 스킬 검증을 담당합니다.
- C++ core는 기본 50Hz 제어·센서 루프를 제공하지만 모든 제어 요청이 이를 거치지는 않습니다.
  Nav2와 로봇별 조작 드라이버를 직접 사용하는 경로에도 별도의 안전 검사가 필요합니다.
- 장소·별칭·좌표와 실행 경험은 SQLite, 비정형 교훈·장면 지식은 벡터 저장소에서 관리합니다.
- 복합 요청은 네이티브 도구 호출을 지원하면 하나의 대화로 처리하며, JSON 계획 경로에서만
  활성화된 분해기가 하위 지시문을 생성합니다.

실행과 기본값은 [설정 가이드](../CONFIGURATION_GUIDE.md), 안전 계약과 사용 가능한 기능은
[스킬 레퍼런스](../SKILLS.md)를 참고합니다. 과거 분석 그림은 현재 실행 계약을 대신하지 않습니다.
